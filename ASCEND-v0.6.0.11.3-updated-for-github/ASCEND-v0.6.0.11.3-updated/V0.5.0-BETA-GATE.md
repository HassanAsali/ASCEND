# ASCEND v0.5.3.1 — Private Beta Gate

Do not invite external testers until these checks pass.

## 1. Database isolation
Run `SUPABASE-SECURITY-AUDIT.sql` in the same Supabase project used by ASCEND.

## 2. Two-account contamination test
1. Account A: create a uniquely named Quest and Project, sync, sign out.
2. Account B on the same browser: sign in. A's name, XP, Quest and Project must never appear.
3. Create different B data, sync, sign out.
4. Sign A back in and unlock its vault. B data must never appear.
5. Repeat A and B on a second device using each account's own recovery key.

## 3. Recovery test
Use Forgot Password, follow the email link, set a new password, then sign in again. Recovery-key encryption should remain independent of the login password.

## 4. Project test
Create a Project with required and optional Quests. The Final Quest must remain locked until every required Quest is complete. Optional Quests must not block it.

## 5. Privacy-mode test
Set AI privacy mode to Private Local. Analyze a Quest and confirm the result reports LOCAL+ / local fallback rather than semantic AI.

## 6. Impact-credit test
A normal completed Project should receive zero S-Rank time credit. Impact credit is never issued by the local fallback, is capped to 1% per audited Project, and 5% lifetime.
