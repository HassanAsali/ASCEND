# ASCEND v0.5.3.4.10 — Quick Regression Checklist

Run these in order after local setup. Stop if one fails and capture the screen/error before changing configuration.

1. **Daily recurrence** — Complete a Daily Quest. Confirm today's card shows **DONE TODAY** with **Undo Today**, one tomorrow card appears with **LOCKED**, and pressing tomorrow's check cannot award XP.
2. **Daily mistake reversal** — Press **Undo Today** on the completed card. Confirm XP and Practice Record fall by exactly the earned amount/one clear, today's card becomes active, and the generated tomorrow card disappears.

3. **Milestones** — Open Milestones. Confirm selected areas show truthful generic paths such as First Verified Step, Practice Record, Substantial Outcome and Capability Growth; no CAD/GitHub/IELTS/late-night achievement should be forced.
2. **Focus recalibration** — System → Recalibrate Focus Areas. Current choices should be preselected. Change one, finish, and confirm all quests, XP and history remain.
3. **Daily counting** — Complete a Daily Quest in one focus area and confirm that area's Practice Record progress rises by one.
4. **Semantic Skill allocation** — Clear `رتب خطة أسبوعك وحدد ثلاث أولويات واضحة`. Confirm Planning receives 40 XP, Organization receives 20 XP, and Consistency receives none.
5. **Recurring Consistency** — Clear a real Daily habit/practice quest and confirm Consistency receives progression.
6. **Core Skills** — Confirm categories now share a concise set of broad skills and Engineering does not automatically add CAD/Design.
7. **Skill migration** — An existing account keeps its prior Skill XP after the first v0.5.3.4.10 load.
8. **Quest AI shortcut** — Open Quests, press **AI Quest Console**, and confirm ASCEND returns to the existing Command Console and focuses its input.
9. **Short laptop auth** — Use the same Windows scaling/browser zoom that produced the screenshots. Confirm Sign In uses the compact two-column layout, needs no long page scroll, and Turnstile passes.
10. **Short mobile auth** — Confirm credentials, Turnstile, status, and Guest access remain visible and comfortable; the large marketing paragraph should not consume the viewport.
11. **Mobile System sheet** — Open System on a short/narrow viewport. Confirm the panel stays inside the screen and every action remains reachable. **Delete Guest Profile** should be present only in Guest and should be compact.
12. **Enlarged desktop rail** — Enlarge browser/Windows scaling while the desktop rail remains visible. Confirm there is no competing visible scrollbar inside the rail and all navigation/account actions remain reachable.
13. **Deleted account message** — On the same browser that deleted a test account, try its old credentials. ASCEND may explain that this browser recorded the account deletion. Arbitrary unknown emails must still use the generic incorrect-email-or-password response.
14. **Fresh Guest** — If an old Guest exists, Welcome should show **Continue Guest Profile** and **Start Fresh Guest**. Start Fresh Guest and confirm onboarding begins with `0 selected`.
15. **Onboarding controls** — Select several categories, press **Deselect all**, and confirm the count returns to zero. Add a custom area and confirm the count updates.
16. **Guest isolation** — In Guest create `ONLY GUEST`. Log out, sign into a cloud account on the same Chrome profile, and confirm `ONLY GUEST` does not exist there.
17. **Account isolation** — In Account A create `ONLY ACCOUNT A`. Sign out and use Account B. Confirm A's quest is absent. Create `ONLY ACCOUNT B`, then return to A and confirm B's quest is absent.
18. **Quest Console position** — Command should show the AI Quest Console before Core Skills.
19. **Single analysis Cancel** — Analyze one quest and confirm both **Cancel** and **Review & Accept** appear. Cancel must discard the analysis without creating a quest.
20. **Arabic AI** — Analyze `سوي انبوكسنق للطابعة الجديدة`. Title, rationale, first action, done condition, breakdown/evidence/tags should be Arabic except natural technical names/acronyms.
21. **English AI** — Analyze an English objective and confirm the prose stays English.
22. **Language override** — Give Arabic input but explicitly request English output, then reverse it. The explicit request must win.
23. **Tutorial** — Replay from System. Walk through all 13 steps: Player Core, Today's Directive, Quest Console, Core Skills, Active Objectives, Quest Board, Project Architect, Guide, Progress, Milestones, System, Cloud Link, Account Safety.
24. **Delete Account** — Use only a disposable test account. Confirm current password + acknowledgement checkbox + fresh Turnstile + final destructive confirmation are all required.

Rank gates and the S-Rank impact-credit cap are intentionally unchanged in this patch.
