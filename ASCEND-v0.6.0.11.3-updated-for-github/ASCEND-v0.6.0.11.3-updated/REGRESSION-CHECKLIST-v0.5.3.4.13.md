# ASCEND v0.5.3.4.13 Regression Checklist

1. On an unlocked trusted device, download the account Recovery File from **System → Cloud Link**.
2. On a new browser/device with no vault key, sign in to an account that already has encrypted cloud progress.
3. Confirm **Unlock your ASCEND progress** appears before System Calibration and no onboarding field can be reached.
4. Import the Recovery File and confirm the existing name, quests, XP, Skills, and history load.
5. Close and reopen the installed PWA; confirm the same device stays unlocked without asking for the file again.
6. Sign out, then sign in again on that device and confirm the account cache remains account-scoped.
7. Analyze a quest and note the displayed XP.
8. Choose Review & Accept without editing reward fields; the dialog and Quest Board must show the same XP.
9. Analyze a batch and use Accept All; every stored reward must equal its analysis reward.
10. Edit minutes, type, priority, difficulty, value, impact, category, or title in the review dialog; XP should recalculate.
11. Send Private Beta feedback and confirm it reaches `beta_feedback`.
