# ASCEND v0.6.0.9 Regression Checklist

## Missed Daily catch-up

1. Keep one unfinished Daily scheduled for an earlier date and reopen/refresh ASCEND.
2. Confirm its badge says it is ready today and reports the number of missed days.
3. Confirm partial subquest checks remain unchanged and Total XP does not increase.
4. Refresh again: no second occurrence or second catch-up activity is created.
5. Complete it normally: exactly one tomorrow occurrence appears locked until tomorrow.

## Habits

1. Open Habits, add a habit with two or more selected weekdays, and optionally set a time/category.
2. On a scheduled day, check it and confirm Done Today/current streak update.
3. Uncheck it and confirm the state reverses exactly.
4. Confirm Total XP, Rank, active-day count, Quest count, and Circle leaderboard do not change.
5. Reload and switch away/back; the habit persists only in the current Guest/account namespace.

## Preserved critical flows

- Voice capture inserts transcript text only; ASCEND stores no audio.
- Accept/cancel/discard clears the Quest Console and review state; batch items can be discarded individually.
- Planner Lists/Semesters and Projects retain structure and do not award XP by organization alone.
- Focus Circles remain opt-in/server-mediated and cannot award XP or promote Rank.
- Guest, account A, and account B remain isolated through login/logout/switching.
- Existing Daily Undo performs an exact reversal and cannot become a reusable XP toggle.

No v0.6.0.9 SQL migration or environment-variable change is required.
